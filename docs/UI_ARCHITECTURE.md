# UI_ARCHITECTURE — Web UI 架构（2026-09-09 v2 中文优先）

## 定位
**Global Intelligence · 全球热点事件情报与 Agent 信息服务**（工具型情报台，非新闻门户）。
信息密度高、零框架、零构建步骤、深色控制台风格。

## 语言策略（§二/三）
- **界面语言：简体中文**（导航/按钮/表单/状态/错误/空态/弹窗/管理后台全中文）
- **内容语言：原文**（文章标题/正文/作者/URL 不翻译；列表标注"原文"）
- 页脚常驻声明："界面语言：简体中文 · 内容保持原文"
- 预留：未来 UI Language 切换（简体中文/English），本阶段未引入翻译 AI

## 结构（单文件 SPA, public/index.html）
```
公开区（无需登录, 只读）: 概览 / 搜索 / 事件 / 来源 / 媒体 / 系统
管理区（admin 会话）: 概览 / 系统状态 / 搜索服务 / 情报采集 / 事件 / 来源(管理) / 媒体
                      / MCP 服务 / API / 用户 / 存储 / 日志 / 系统诊断 / 设置
登录: 弹窗（/api/auth/login, HttpOnly Cookie）
```
- 搜索：五个范围（全部/互联网/我的情报库/事件/媒体）；结果带「互联网·来源」「情报库」「事件·已采集」标签，绝不混淆
- 事件详情：名称/首次发现/最近更新/热度/来源数/文章数/视频数/时间线（原文标题）
- MCP 管理页：状态/Endpoint/复制地址/复制配置/创建 Token（仅显示一次弹窗）/撤销/恢复/删除/调用统计/工具清单（中文说明+参数）/测试 MCP（逐步✓✗）
- 用户页：创建（角色选择）/重置密码/禁用启用（admin 内置保护）
- 系统诊断页：16 项检查（✓/✗+明细）+「复制诊断报告」
- 设置页：只读展示（保留策略/批次/磁盘分级/AI Provider 状态——AI 默认全部禁用）

## 响应式
- CSS Grid auto-fit + 640px 断点（导航/搜索框/内边距自适应）
- 表格容器 `.tw{overflow-x:auto}`（手机不横向破版）
- 已验证：桌面 Chrome / 手机宽度模拟（CSS 层面）

## 真实数据原则
- 所有计数/状态来自生产库与运行时（/api/status / /api/admin/*）
- 无数据显示「暂无数据 / 未配置 / 等待首次运行」，绝不伪造
- MCP 状态 = 运行时 mcpHandler 真值；AI Provider 状态 = env.local 存在性检查（不读值）
